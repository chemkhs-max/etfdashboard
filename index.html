실시간 데이터 연동 및 정적 배포 안내

네이버 증권 API는 브라우저 보안 규정(CORS)에 의해 제3자 도메인에서의 직접 비동기 호출이 차단될 수 있습니다. 본 대시보드는 정적 페이지 배포(GitHub Pages, Vercel, 로컬 HTML 실행)를 고려하여 다음과 같은 최적의 3단계 연동 방식을 제공합니다:

1. uv 기반 초고속 데이터 갱신 스크립트

터미널에서 아래 명령어를 실행하면 약 1.5초 만에 전체 1,171개 ETF 최신 데이터를 수집하여 data/etfs.json과 오프라인 스냅샷을 갱신합니다.

uv run python fetch_data.py

2. 정적 웹사이트 배포 (GitHub Actions 자동화)

제공된 GitHub Actions 워크플로우(.github/workflows/update_data.yml)를 이용해 평일 장마감 후 자동으로 데이터를 수집하고 GitHub Pages에 무료 배포할 수 있습니다.

3. 수동 JSON 데이터 즉시 업로드

상단의 [JSON 업로드] 버튼을 통해 새로 수집된 etfs.json 파일을 브라우저에 바로 올려 즉각 탐색할 수 있습니다.
